Implemented an enterprise-grade AI skill called database_modernization_skill focused specifically on database implementation modernization at repository level. Unlike general application modernization, this skill targets only database-related components such as queries, ORM mappings, drivers, configurations, and integrations, enabling transformation from one database technology to another without impacting unrelated business logic. It supports relational, NoSQL, and cloud databases across multiple programming languages/frameworks and generates production-ready modernization guidance and code transformations.
